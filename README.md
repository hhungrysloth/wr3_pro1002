In this module I learned how to connect internet to code, how TCP/IP have the rules for moving data and that socket API lets programs send and receive packets between hosts. This module made it more clear how web servers, HTTP and browsers need to work together to end up as webpages. 

Not neccessarily very surprising, but interesting, how much small, clearly defined protocols working together behind the scenes is the foundation for communication, and we often don't think about it.
